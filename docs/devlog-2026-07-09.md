## 오늘 한 것

### 1. 인스타그램 가이드 이미지 처리
- 실제 인스타그램 스크린샷으로 SVG 목업 대체
- Python PIL로 각 이미지 크롭 + 강조 박스(둥근 테두리, 반투명 오버레이) 처리
- 총 6장 완성: `insta_step1_settings.png` ~ `insta_step6_config.png`
- 수정 이력: 헤더 제거, 잘못된 강조 위치 수정 (step2 "내 정보 및 권한", step3 "내 정보 내보내기" 버튼), 테두리 삐죽 문제 수정

### 2. 점수 정규화 시스템 도입
- 이전: 메시지 수 그대로 합산
- 이후: 플랫폼별 최댓값을 100점으로 정규화
  - 카카오: `(내 메시지 수 / 카카오 최대) × 100`
  - 인스타: `(내 인스타 점수 / 인스타 최대) × 100 × 2`
  - 합산: 0~300점

### 3. 인스타 메인 / 카카오 서브로 구조 개편
- 온보딩: 플랫폼 선택 제거 → 인스타 그라디언트 히어로 카드 + 카카오 한 줄 보조
- 업로드 화면: 인스타 필수(항상 표시) + 카카오 아코디언 (인스타 완료 후에만 노출)
- 배지("필수"/"선택사항") 제거, 전체적으로 시각 단순화

### 4. UI 개선
- CSS 애니메이션 추가: `fadeSlideUp` 0.08초 stagger, `fadeIn`, `scaleIn`

- 온보딩 히어로 영역 그라디언트 카드
