Image is an avatar/thumbnail placeholder — no real photography exists in the source, so it renders a gradient-filled shape with initials.

```jsx
<Image shape="round" size={48} initials="민" />
<Image shape="square" size={64} initials="AI" />
```

Use `round` for friend avatars in ranking rows, `square` for chart/screenshot placeholders (e.g. "순위 변동 추이" mini-chart slot).
